# 📖 Overview

LapGenius is a modern web platform for buying and selling laptops.

The platform combines an advanced e-commerce system with Artificial Intelligence technologies to help users choose the most suitable laptop and estimate its expected market price.

The system also includes complete seller and administrator dashboards, a real-time notification system, an integrated messaging system, and multiple payment methods including Sham Cash.

---

## 💳 Payment System

Supported payment methods:

### Cash on Delivery

- Order remains pending.
- Stock decreases only after seller approval.

### Sham Cash

- QR Code payment.
- Upload payment proof.
- Stock decreases immediately.
- If the seller rejects the order, stock is automatically restored.
- Payment proof is available to the seller during order review.
